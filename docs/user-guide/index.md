# User guide

This guide is for engineers who use Imbi every day. Each page starts from
a task, for example "find my open pull requests" or "restore a document".
For the administrator tasks, see the Administration section.

Most pages of Imbi show the data of one organization. Select the
organization in the top bar first.

| Page | Read it to |
|---|---|
| [Projects](projects.md) | Find projects, read a project page, and make a project |
| [Releases and deployments](releases-and-deployments.md) | Make a release, promote it, and block it |
| [Drift](drift.md) | Understand the three kinds of drift and their badges |
| [Doctor](doctor.md) | Read the findings of a project, and fix them |
| [Operations log and scoring](operations-log-and-scoring.md) | Record and read operations, and understand project scores |
| [Pull requests and dependencies](pull-requests-and-dependencies.md) | Find pull requests and commits, edit project dependencies, and read package data from SBOMs |
| [Documents, reports, and the dashboard](documents-and-reports.md) | Write documents, read the reports, and change the dashboard |
| [Search and the assistant](search-and-assistant.md) | Use Cmd+K search, and ask the assistant |
| [Your settings](settings.md) | Connect your accounts, and make API keys |
